# Student Management System in C

## Project Overview
The Student Management System is a menu-driven C programming project designed to manage student records efficiently. It uses structures, functions, and file handling to store and manage student information.

## Features
- Add Student Records
- Delete Student Records
- Update Student Details
- Search Student Records
- Display All Student Records
- Exit the Program

## Technologies Used
- C Programming Language
- Structures
- Functions
- File Handling

## Student Details
The system stores:
- Roll Number
- Student Name
- Marks

## File Handling
Student records are stored in a text file named `students.txt`. This helps maintain records between program operations. Persistence across separate online compiler sessions depends on the compiler environment.

## How to Run
1. Download or clone this repository.
2. Open the source file `student_management.c` in a C compiler.
3. Compile and run the program.
4. Select an option from the menu.
5. Manage student records.

## Menu Options
1. Add Student
2. Delete Student
3. Update Student
4. Search Student
5. Display Students
6. Exit

- Using functions for modular programming.
- Learning file handling operations.
- Managing records using C programming.
